- [Working Nomads](https://www.workingnomads.com) - Curated remote job listings for digital nomads.

## Contributing

Contributions are welcome and encouraged. This list is maintained by the community.

To add a new job board:

1. Fork this repository
2. Add your job board to the appropriate section
3. Make sure the board is genuinely useful for tech job seekers in Europe
4. Submit a pull request with a clear title
